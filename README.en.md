# Luna Branding

Shared icons, logos and wallpapers for the Luna desktop.

> **Languages:** [Polski](README.pl.md) · [English](README.en.md) · [Deutsch](README.de.md)

## Part of the Luna project

This repository ships the **Luna-Icons** theme (pastel freedesktop icons),
the libLuna, Luna and Selene logos, and the wallpapers. The `luna-branding`
package installs them into `/usr/share/icons`, `/usr/share/pixmaps` and
`/usr/share/wallpapers`, so every desktop application uses one icon set.
