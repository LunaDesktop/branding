# Luna Branding

Wspólne ikony, logo i tapety środowiska Luna.

> **Języki:** [Polski](README.pl.md) · [English](README.en.md) · [Deutsch](README.de.md)

## Część projektu Luna

Repozytorium zawiera motyw **Luna-Icons** (pastelowe ikony freedesktop),
logo libLuny, Luny i Selene oraz tapety. Pakiet `luna-branding` instaluje je
w `/usr/share/icons`, `/usr/share/pixmaps` i `/usr/share/wallpapers`, dzięki
czemu wszystkie aplikacje środowiska korzystają z jednego zestawu.
