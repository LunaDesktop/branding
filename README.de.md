# Luna Branding

Gemeinsame Icons, Logos und Hintergrundbilder für den Luna-Desktop.

> **Sprachen:** [Polski](README.pl.md) · [English](README.en.md) · [Deutsch](README.de.md)

## Teil des Luna-Projekts

Das Repository enthält das **Luna-Icons**-Theme (pastellfarbene
freedesktop-Icons), die Logos von libLuna, Luna und Selene sowie die
Hintergrundbilder. Das Paket `luna-branding` installiert sie nach
`/usr/share/icons`, `/usr/share/pixmaps` und `/usr/share/wallpapers`.
